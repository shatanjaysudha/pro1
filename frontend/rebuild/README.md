# Rebuild Deliverables

This folder contains implementation and documentation deliverables for the automation + rebuild directive.

## Structure
- `00-references`: pattern extraction from benchmark sites
- `01-homepage`: spec + component exports
- `02-article-panels`: panel architecture + logic outputs
- `03-resources-hub`: templates + search/filter/autocomplete outputs
- `04-intellectual-hub`: hub structure + AI assistant outputs
- `05-motion`: motion library + applied motion tokens
- `06-search-filter`: global search and autocomplete system docs
- `07-seo`: metadata and JSON-LD modules
- `08-analytics`: event mapping and GA4/GTM config
- `09-content-json`: structured content exports
- `10-qa`: QA checklist and screenshot capture plan
- `11-performance`: pre/post performance report
