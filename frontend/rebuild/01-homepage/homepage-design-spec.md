# Homepage Design Spec

## Viewports
- Desktop: 1280px grid, 2-column hero, 48px section rhythm.
- Tablet: single-column hero with preserved action priority.
- Mobile: stacked cards, full-width CTAs, minimum 44px touch targets.

## Final section order
1. Hero
2. Brand Story
3. Featured Categories
4. Value Proposition
5. Engagement Anchors
6. Core Section Preview
7. Social Proof
8. Featured Resources
9. Go Deeper CTA
10. Newsletter Signup

## UX goals
- Immediate clarity in first viewport.
- Fast path to depth content in <=2 interactions.
- Stable visual rhythm and lower cognitive load.
- Increased internal navigation into hub/resource/article pages.

## Accessibility
- Semantic section headings (`h1` -> `h2` progression).
- Keyboard-usable controls and visible focus states.
- Motion reduction respected through global reduced-motion mode.
