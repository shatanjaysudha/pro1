# Resources Hub Templates

## Sections
1. Resources hero with search input
2. Quick categories
3. Filter toolbar (category + tags + clear)
4. Featured resources
5. Resource library grid
6. Goal-based learning pathways
7. CTA strip
8. Analytics map
9. Footer quick links

## Dynamic behavior
- Search query is normalized and filtered instantly.
- Category and tag filters update result set in real-time.
- Featured set adapts based on active filters.
- Resource cards route to details/download/template pages.
- Suggestion chips + datalist autocomplete added for lower-friction discovery.
