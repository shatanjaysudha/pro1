# Intellectual Hub Page

## Core structure
- Hub intro and search/filter controls
- AI category assistant with starter intents
- Hub section cards (frameworks, research, roadmaps, case studies)
- Save-to-library actions
- Interactive roadmap timeline

- Accepts natural-language goal input
- Scores hub cards against query terms + synonym expansion
- Returns top recommendations with reason text
- Supports one-click open actions and analytics tracking
