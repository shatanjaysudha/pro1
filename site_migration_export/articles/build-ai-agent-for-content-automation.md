# How I Built My First AI Content Agent

Shatanjay Sudha | August 2025

## My Content Creation Challenge

A few weeks ago, I found myself stuck. Every morning, I’d wake up thinking, “What should I post today?” And even though I had the ideas, finding the latest AI news, writing a reel script, crafting a LinkedIn post, and designing a good image… felt like a full-time job.

That’s when I decided to do something different. Something I wish I had done earlier.

I built an AI agent that:

### Finds AI News

Discovers the latest AI developments every morning

### Creates Scripts

Writes Instagram reel scripts in my unique voice

### Prepares Posts

Crafts ready-to-publish LinkedIn captions

### Generates Images

Creates custom visuals for each post

And no—I didn’t write a single line of code. In this blog, I’ll walk you through exactly how I built this, how you can do it too, and how it’s changed the way I create content forever.

## Why Build an AI Content Agent?

Let’s be honest: showing up on social media consistently is hard. Whether you’re a creator, a startup founder, or just someone who wants to grow online—you need to post, and post often. But the work behind each post?

- Finding what’s trending
- Writing copy that hooks
- Creating visuals
- Scheduling and posting

It adds up. Fast. What I really wanted was this: “A system that brings me daily, ready-made, high-quality content so I can just hit record or post—and grow my brand.” And that’s exactly what I built. Let me show you how you can build it too.

## Tools I Used

All these tools are free or have free plans:

| Tool | What It Does |
| --- | --- |
| Make.com | The no-code platform that connects everything together |
| Perplexity AI | Finds and summarizes the latest AI news |
| Gemini by Google | Writes scripts, posts, and even generates images |
| Gmail | Sends the finished package to my inbox every morning |

You don’t need to be technical. If you can drag and drop, you’re good to go.

## Step-by-Step Guide

Let’s break this down. It took me about 45 minutes from start to finish—and once it was set up, it runs on its own every day.

### Create a Free Make.com Account

Go to make.com and sign up. Once inside, click on “Create a new scenario.” This is where all the magic begins.

### Add a Trigger – a Simple Webhook

This webhook is like a button. When it’s pressed (either manually or on a schedule), it starts the workflow.

```
Search for Webhooks
Select Custom Webhook
Name it daily_ai_content
Save and copy the webhook link
```

We’ll automate this to run every day at 11 AM—but first, we’ll test it manually.

### Pull the Latest AI News with Perplexity

Add a module for Perplexity AI > Create Chat Completion. Connect your API key (get it from perplexity.ai/account/api). Choose the Sonar model. Use this prompt:

```
Find the most important AI tool or product launched in the past 5 days. Summarize it clearly and provide a link. Respond only in this format:
{
  "title": "Tool name",
  "summary": "Short paragraph summary",
  "url": "Link to main source"
}
```

Now you’ve got the freshest AI news, daily.

## Final Thoughts

I built this AI agent to help me show up online every day without burning out. And honestly, it works like magic. Now, instead of wasting time figuring out what to post, I just read the script, record the reel, and hit post on LinkedIn. That’s it.

If you’re serious about growing your personal brand, saving time, or just becoming more consistent with content—build your own version of this AI agent today. It’ll change the game for you, like it did for me.
