## Discover Corpus In App
- The primary high-volume Discover corpus is generated in `frontend/js/main.js` from `DISCOVER_TOPIC_CLUSTERS`.
- Each generated long-form article now includes:
  - 1800+ words (target 2000–3500)
  - SEO block (meta title, meta description, slug, primary + secondary keywords)
  - Hero + 3 supporting image prompts (alt + caption + prompt text)
  - Internal link path (resource/template links + related article + hub)
  - Outbound citations to high-authority references
