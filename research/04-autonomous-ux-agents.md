# Domain 4: Autonomous UX Agents

## Major concepts
- Embedded copilot that can reason over user context and site content.
- Tool-using agents with constrained actions and explicit approvals.
- Citation-first responses for trust and quality assurance.
- Multimodal input for low-friction interaction (text + voice).

## Real examples
- OpenAI Agents and Voice/Realtime guides define practical agent workflows.
- Anthropic computer use documents task automation with guardrails.
- Search Live pattern demonstrates conversational interaction in discovery contexts.

## Implementation references
- See `research/SOURCES.md` sections: `Agents and multimodal`, `Search and personalization`.

## Implementation guidance for shatanjaysudha.com
- Add a right-panel copilot in desktop and full-screen modal on mobile.
- Start with three tools:
  - `search_content`
  - `build_learning_path`
  - `recommend_resource`
- Require user approval for all navigation-changing or conversion actions.

## Suggested KPI targets
- Copilot session completion: >35%.
- Copilot-assisted conversion lift: +8%.
- User-rated helpfulness: >4.2/5.
