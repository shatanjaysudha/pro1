# Article Engine Pack

Generated on: 2026-02-14

This folder contains a full SEO/Discover article planning package for `https://shatanjaysudha.com`.

## Files

- `topic_map.json`: 100 topics with keyword, intent, word-count target, difficulty, virality/ranking rationale, and related links.
- `article_output_blueprints.json`: structure-ready output blocks per topic (title/meta/slug/hero/sections/Discover checks).
- `internal_linking_map.json`: automatic 2 same-category + 3 cross-category related-link suggestions per topic.
- `article_template.md`: reusable article format for publish-ready drafts.
- `article-drafts/`: 8 long-form pillar drafts (one per category), each with TL;DR, steps, mistakes, pro tips, FAQ, and related links.
- `trending_next_30_days.json`: trend-driven publish ideas for the next 30 days.
- `evergreen_pillar_suggestions.json`: evergreen pillar candidates.
- `content_cluster_map.json`: topic cluster-to-cluster bridge map.
- `topic_authority_roadmap.md`: 90-day authority build plan.
- `weekly_publishing_calendar.csv`: 12-week editorial schedule.
- `quality_report.json`: readability and structure checks.
- `competitor_structure_analysis.md`: structure findings from Medium, MakeUseOf, iPhoneLife, and Jeff Su.
- `research_sources.md`: external references used to build the plan.
