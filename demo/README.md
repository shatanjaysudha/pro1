# Demo

## Files
- `index.html` - interactive motion showcase
- `motion-playground.css` - visual styling
- `motion-playground.js` - spring tuning + live preview

## What this demo shows
- List reveal with staggered spring entrance.
- Panel transition with spring slide/settle.
- Hover micro feedback patterns.
- Live tuning controls for stiffness/damping.
- Reduced-motion simulation toggle.

## Run
Serve the project root and open `/demo/index.html`.
